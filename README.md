# Dahab Store — نظام إدارة متجر مستحضرات التجميل (نسخة بسيطة)

يعمل على جهازك **بدون إنترنت**، وكل البيانات محفوظة عندك في `%APPDATA%\DahabStore`. لا GitHub ولا تحديثات تلقائية ولا شيء يتصل بالخارج.

## التشغيل
1. ثبّت **Python** مرة واحدة (مجاني): https://www.python.org/downloads/windows/ — وعلّم على **Add python.exe to PATH** أثناء التثبيت.
2. دوبل كليك على **run.bat**.
   - أول مرة فقط يجهّز نفسه (يحتاج إنترنت دقيقة أو اتنين لتحميل المكتبات).
   - بعدها يفتح البرنامج في نافذة مستقلة، ويشتغل بدون إنترنت.
3. الدخول الأول: المستخدم `admin` وكلمة السر `admin123` (يطلب تغييرها).

## ملاحظات
- البرنامج **لا يقفل نفسه أبدًا**. لو قفلت النافذة بالغلط، دوبل كليك على `run.bat` يفتحها تاني فورًا على نفس البرنامج الشغّال.
- يشتغل في الخلفية بدون نافذة سودا. لإيقافه: Task Manager ← `pythonw.exe` ← End task (غير ضروري، النسخ الاحتياطي تلقائي كل 15 دقيقة عند وجود تغيير).
- **تشغيل تلقائي مع الويندوز (اختياري):** اضغط Win+R واكتب `shell:startup` ثم انسخ اختصار `run.bat` داخل الفولدر.
- **بياناتك:** نفس مكان النسخة القديمة (`%APPDATA%\DahabStore`) فتفضل كما هي.
- لو كان **Dahab Store القديم (المثبّت)** شغّال، أغلقه أو احذفه من Add or remove programs (البيانات لا تتأثر).
