# Dahab Store — نظام إدارة متجر مستحضرات تجميل

تطبيق (Flask + SQLite) بواجهة عربية RTL بتصميم أسود وذهبي، مبني على وثيقة المتطلبات (SRS). يعمل **بدون إنترنت** ويحفظ كل شيء على جهاز المحل.

## كيف تشغّله
- **نسخة ويندوز (للمحل):** ملف `DahabStore-Setup.exe` يُبنى تلقائيًا على GitHub — الخطوات في **`BUILD_AR.md`**.
- **للتطوير/التجربة:**
  ```bash
  pip install -r requirements.txt
  python app.py            # ثم افتح http://localhost:5000
  python seed.py           # (اختياري) بيانات تجريبية على قاعدة فارغة
  python test_smoke.py && python test_features.py && python test_safety.py
  ```
- الدخول الأول: `admin` / `admin123` — يطلب النظام تغييرها فورًا.
- الاستضافة على الإنترنت (اختياري): `DEPLOY_AR.md`.

## العملاء والعروض والخصومات
- **بيانات العميل من الكاشير:** عند إصدار الفاتورة يدخل الكاشير رقم هاتف العميل واسمه (إجباري افتراضيًا، والمدير يستطيع جعله اختياريًا من صفحة العملاء). العميل الجديد **يُضاف تلقائيًا إلى قائمة العملاء عند المديرين**. نفس الرقم بصيغ مختلفة (`+20 100…` / `0100…`) يُعتبر نفس العميل.
- **خصم العميل:** يحدده المدير لكل عميل (نسبة %) من قائمة العملاء. بمجرد أن يكتب الكاشير رقم الهاتف يظهر له اسم العميل وخصمه ويُطبَّق تلقائيًا على الفاتورة ويظهر على الإيصال. الكاشير لا يرى قائمة العملاء ولا يستطيع تغيير الخصم، والبحث بالهاتف مطابقة تامة فقط.
- **العروض:** يضيفها المدير بعنوان وتفاصيل وصورة وتاريخ بداية/نهاية ونسبة خصم، ويربطها بمنتج فيُطبَّق سعر العرض تلقائيًا في الكاشير طوال مدته. الكاشير يرى العروض الجارية فقط (في صفحة «العروض» وفي شاشة الكاشير). العرض المنتهي أو الذي لم يبدأ أو المؤرشف لا يُطبَّق.
- **صور المنتجات:** يرفعها المدير من صفحة المنتج (تُصغَّر وتُضغط تلقائيًا) وتظهر للكاشير في البحث والسلة.
- ترتيب الخصومات: سعر العرض أولًا، ثم خصم العميل على الإجمالي، ثم الخصم اليدوي (للمديرين فقط). الخصم لا يتجاوز إجمالي الفاتورة.

## حماية البيانات (لا صيانة ولا ضياع)
نسخ احتياطي تلقائي مُتحقَّق منه (عند التشغيل، كل 15 دقيقة عند التغيير، عند الإغلاق، قبل الترقية) مع نسخة اختيارية على فلاشة/قرص خارجي تشمل الصور · فحص سلامة القاعدة عند كل تشغيل واسترجاع تلقائي عند التلف · تعافٍ آمن بعد انقطاع الكهرباء · **لا حذف نهائي** (أرشفة وإلغاء بدل الحذف، ويفرضه تريجر في قاعدة البيانات) · دفتر حركة مخزون لا يُعدَّل يطابق الأرصدة دائمًا + جرد · سجل مراجعة لكل عملية · استرجاع من صفحة «النسخ الاحتياطي» مع نسخة أمان قبله.

## الكاشير والأجهزة
- **قارئ الباركود/QR (USB أو بلوتوث):** يعمل مباشرة كلوحة مفاتيح، حتى لو لم يكن المؤشر في خانة البحث. زر «📷 كاميرا» يمسح QR والباركود (يحتاج Chrome/Edge وlocalhost أو HTTPS).
- **الطباعة** (كارت «الأجهزة»): طباعة المتصفح لأي طابعة بمقاس 80 أو 58 مم، أو إرسال مباشر للطابعة الحرارية ESC/POS عبر USB أو Serial/بلوتوث (الفاتورة تُرسم كصورة فيظهر العربي صحيحًا). زر «طباعة تجريبية» قبل البدء. على ويندوز قد تحتاج تعريف WinUSB (أداة Zadig) للطباعة المباشرة عبر USB، وإلا استخدم طباعة المتصفح.

## التحديثات وصفحة العروض و QR
- **التحديث بدون إعادة تثبيت:** النسخ الاحتياطي والتحديثات ▸ رفع ملف `DahabStore-update-N.zip` (للمديرين). يُفحص ثم يُطبَّق ويُوزَّع على باقي الأجهزة عبر GitHub، مع تراجع تلقائي عند الفشل.
- **صفحة العروض العامة** على GitHub Pages بنفس تصميم النظام، تُحدَّث تلقائيًا مع كل تعديل في «العروض».
- **QR على الفاتورة** يفتح صفحة العروض، مع رقم المحل (اتصال/واتساب) — يُضبط من «إعدادات المتجر».
- التفاصيل والإعداد: `BUILD_AR.md` (آخر قسم). الاختبارات: `python test_cloud.py`.
